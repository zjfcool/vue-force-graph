# vue-force-graph-2d

A Vue component for rendering 2D force‑directed graphs, powered by the [force-graph](https://github.com/vasturiano/force-graph) library.

## Quick start

### Install

```bash
npm install vue-force-graph-2d --save
```

### Usage

1. Local Registration (Recommended)
   Import the component only where needed.

```js
<template>
  <ForceGraph2D :graph-data="graphData" />
</template>

<script setup>
import ForceGraph2D from 'vue-force-graph-2d'

const graphData = {
  nodes: [ /* ... */ ],
  links: [ /* ... */ ]
}
</script>
```

1. Global Registration
   Register the component once in main.js, then use it anywhere without importing.

```js
// main.js
import { createApp } from "vue";
import App from "./App.vue";
import ForceGraph2D from "vue-force-graph-2d";

const app = createApp(App);
app.use(ForceGraph2D);
app.mount("#app");
```

```js
<!-- Any .vue file -->
<template>
  <ForceGraph2D :graph-data="graphData" />
</template>

<script setup>
const graphData = {
  nodes: [ /* ... */ ],
  links: [ /* ... */ ]
}
</script>
```
