# vue-force-graph-vr

[![npm version](https://img.shields.io/npm/v/vue-force-graph-vr)](https://www.npmjs.com/package/vue-force-graph-vr)

## Quick start

### Install

```bash
npm install aframe
npm install vue-force-graph-vr
```

### Usage

1. Local Registration (Recommended)
   Import the component only where needed.

```js
<template>
  <ForceGraphVR :graph-data="graphData" />
</template>

<script setup>
import "aframe"
import ForceGraphVR from 'vue-force-graph-vr'

const graphData = {
  nodes: [ /* ... */ ],
  links: [ /* ... */ ]
}
</script>
```

1. Global Registration
   Register the component once in main.js, then use it anywhere without importing.

```js
// main.js
import { createApp } from "vue";
import "aframe";
import App from "./App.vue";
import ForceGraphVR from "vue-force-graph-vr";

const app = createApp(App);
app.use(ForceGraphVR);
app.mount("#app");
```

```js
<!-- Any .vue file -->
<template>
  <ForceGraphVR :graph-data="graphData" />
</template>

<script setup>
const graphData = {
  nodes: [ /* ... */ ],
  links: [ /* ... */ ]
}
</script>
```

### Events

| Name          | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Type       | Default |
| :------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :--------- | :------ |
| `node-click`  | Callback function for node (left-button) clicks. The node object and the event object are included as arguments `onNodeClick(node, event)`.                                                                                                                                                                                                                                                                                                                                                                    | `function` | `-`     |
| `node-hover`  | Callback function for node mouse over events. The node object (or null if there's no node under the pointer line of sight) is included as the first argument, and the previous node object (or null) as second argument: `onNodeHover(node, prevNode)`.                                                                                                                                                                                                                                                        | `function` | `-`     |
| `link-click`  | Callback function for link (left-button) clicks. The link object and the event object are included as arguments `onLinkClick(link, event)`.                                                                                                                                                                                                                                                                                                                                                                    | `function` | `-`     |
| `link-hover`  | Callback function for link mouse over events. The link object (or null if there's no link under the pointer line of sight) is included as the first argument, and the previous link object (or null) as second argument: `onLinkHover(link, prevLink)`.                                                                                                                                                                                                                                                        | `function` | `-`     |
| `resize`      | Callback function for wrapperElement resize. The new size is included as single argument `onResize({ width, height })`.                                                                                                                                                                                                                                                                                                                                                                                        | `function` | `-`     |
| `dag-error`   | Callback to invoke if a cycle is encountered while processing the data structure for a DAG layout. ### Input JSON syntax

```json
{
    "nodes": [
        {
          "id": "id1",
          "name": "name1",
          "val": 1

        {
          "id": "id2",
          "name": "name2",
          "val": 10
        },
        ...
    ],
    "links": [
        {
            "source": "id1",
            "target": "id2"
        },
        ...
    ]
}
```
